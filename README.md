## 🎯 The problem

Site managers and procurement teams still order materials through phone calls, WhatsApp messages and handwritten lists. Orders get lost, quantities are misunderstood, and nobody can easily find what was ordered for which project last month.

## 💡 The solution

A focused ordering app organised around **projects** and **suppliers**. Pick a project, pick a supplier, add the items and quantities — and the app produces a clean, professional PDF order that can be emailed or shared instantly. Every order is stored and searchable.

---

## ✨ Key features

| Feature | What it does |
|---|---|
| 🏗️ **Project management** | Create and manage the projects that orders belong to. |
| 🏭 **Supplier directory** | Keep supplier contacts and details in one place. |
| 🧾 **Order creation** | Multi-item orders with quantities and specifications. |
| 📄 **Automatic PDF generation** | Professional, branded purchase-order PDFs generated on the device. |
| ✉️ **Email & share** | Send orders to suppliers by email or share through any app. |
| 🔎 **Order history** | Filter and search every past order by project, supplier or date. |
| 🔐 **Secure sign-in** | Email/password authentication with per-user data. |
| 🎯 **Material-only focus** | Intentionally no pricing — keeps the workflow fast and purpose-built. |

## 🏗️ Architecture & engineering highlights

- **GetX MVC structure** — clear separation of `controllers · models · services · routes · views · widgets`.
- **Firebase backend** — Authentication, Cloud Firestore, Cloud Storage and Cloud Functions for server-side tasks such as sending order emails.
- **On-device PDF engine** — `pdf` + `printing` for crisp documents with preview, print and share.
- **Native sharing** — OS share sheet integration for quick delivery to suppliers.
- **Secure by design** — per-user Firestore data isolation and server-side secrets.
